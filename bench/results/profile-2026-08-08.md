# Baseline CPU profile - 2026-08-08

`sample` (12s and 10s captures) over `orgbench run` in release, on `syn-prose.org` and
`syn-emphasis.org`, at the baseline commit (post triple-parse fix, pre optimization).
Raw capture files were not committed; the per-symbol counts below are transcribed from them.
Method: macOS `sample`, flat "sort by top of stack" view, share = samples / total samples.

## Ranking (stable across both profiles, order varies)

| Cost center | syn-prose | syn-emphasis | What it is |
|---|---|---|---|
| Allocation churn | ~24% | ~33% | malloc/free/memset/retain/release/dictionary+array deinit: per-line `[Unicode.Scalar]` arrays, `String(scalars:)` round-trips, `[String: OrgJSON]` node dictionaries |
| Unicode property lookups | ~25% | ~10% | `_swift_stdlib_getBinaryProperties` + `getNumericType` + `GeneralCategory` metadata: `isLetterScalar` / `isNumberScalar` / border classes hitting ICU-backed tables per scalar |
| Hashing | ~7% | ~6% | `Hasher.combine/_finalize`, `Set<Unicode.Scalar>.contains`, `String.hash` - small-set predicates and dictionary keys |
| Iterator/copy overhead | ~5% | ~6% | `IndexingIterator.next`, `Sequence.map`, `_copySequenceContents`, `String._slowFromCodeUnits` |
| Plain-link scanning | ~4.5% | - | `plainLinkCouldStart` + `registeredLinkTypeLength` + `plainLinkEnd` per-position probing |
| Notables | | | `ObjectContainer.permittedObjects.getter` visible at ~1% - recomputed per call; `___chkstk_darwin` ~2% - large stack frames |

## What this orders

1. ASCII fast path in `ParserPrimitives` predicates (biggest single symbol, lowest risk).
2. Representation: flat scalar buffer + slice-based object layer (kills the alloc churn the
   line/string round-trips cause; the remaining churn is node dictionaries - Phase 3's call).
3. Replace tiny `Set<Unicode.Scalar>` predicates with switch/range tests (hashing share).
4. Cache `permittedObjects` per container; revisit plain-link probing order.

Baseline throughput (same build, `results/baseline-2026-08-08.tsv`): 1.9-2.8 MiB/s synthetic,
~2.5 MiB/s real files.
